# Game Development Roles for the Elemelons Dungeon Crawler Project

---

## Role Summary

- **Project Manager & Game Designer**: Leads the project, ensures strategic goals are met, oversees the SCRUM process, and defines the game’s vision and design.
- **Asset Developer & Visual Designer**: Focuses on asset creation, visual design, and graphical integration within Unity.
- **Gameplay & Systems Developer**: Handles core game mechanics, testing, and optimization of gameplay logic.

---

## 1. Project Manager & Game Designer (Strategic and Administrative Role)

### Key Responsibilities:
- **Project Management**: Oversee the SCRUM process in Jira. Break the project into epics, user stories, and tasks. Track sprint goals.
- **Game Design**: Define game mechanics, narrative, level design, and player experience. Create and maintain the Game Design Document (GDD).
- **Coordination & Communication**: Act as the liaison between the graphical/asset developer, the logical/gameplay developer, and external stakeholders. Ensure smooth team communication.
- **Version Control Management**: Supervise GitHub repositories, review pull requests, and ensure adherence to the branching strategy (GitFlow).
- **Administrative Work**: Handle meeting schedules, maintain project documentation, and delegate issues in Jira.

---

## 2. Asset Developer & Visual Designer (Art and Asset Management Role)

### Key Responsibilities:
- **3D/2D Asset Creation**: Design and develop all in-game assets, including characters, animations, textures, UI elements, and environments.
- **Unity Integration**: Implement assets into Unity, ensuring functionality (e.g., prefabs, shaders, and lighting).
- **Visual Style**: Maintain consistent art style across the game, creating an immersive visual experience.
- **Graphics Optimization**: Optimize assets for performance, including texture sizes, draw calls, and memory usage.
- **Collaboration with Logical Developer**: Ensure graphical elements integrate seamlessly with gameplay features.

---

## 3. Gameplay & Systems Developer (Testing and Logic Development Role)

### Key Responsibilities:
- **Core Game Mechanics**: Develop key gameplay systems, including movement, combat, inventory, AI, and procedural dungeon generation.
- **Code Quality & Testing**: Write clean, modular code. Implement unit tests, functional tests, and automated testing using Unity Test Runner.
- **Gameplay Systems**: Integrate systems such as health, skill progression, and dungeon generation in alignment with game design.
- **Performance Optimization**: Focus on performance, memory usage, and smooth gameplay.
- **Debugging**: Investigate crashes, fix gameplay-related issues, and optimize performance for different platforms.

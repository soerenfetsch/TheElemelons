void EarthDungeonTileVizualizer.PaintFloor ( MapData mapData)
inline

Paints the floor tiles at the given positions in the map data. This method initializes the atlas tilemap, calculates the center of each room, and determines the possible area of the source tilemap. It then uses a random seed to select a starting point and paints the floor tiles based on the positions and room types. If a floor position is at the rim of the floor, it uses the border tiles; otherwise, it maps between the floor positions and the positions on the atlas tilemap.
